# Отчет по задаче 1. Максимум и минимум

**1. Идея решения и обоснование выбора структуры данных:**
Используется обычный массив. Идея заключается в инициализации переменных `min` и `max` первым элементом, после чего происходит один линейный проход по массиву с обновлением этих переменных при нахождении меньшего или большего значения. Массив выбран как наиболее подходящая структура для последовательного перебора.

**2. Анализ асимптотики:**
- **Время:** O(n), где n — длина массива (один проход).
- **Память:** O(1) (дополнительная память не выделяется, только переменные).

**3. Примеры ручных тестов и их важность:**
1. `[3, 1, 4, 1, 5, 9, 2, 6]` → `1 9`. Проверяет базовый случай с дубликатами минимума.
2. `[7]` → `7 7`. Граничный случай: массив из одного элемента.
3. Пустой массив → `IllegalArgumentException`. Проверяет корректную обработку ошибок.
