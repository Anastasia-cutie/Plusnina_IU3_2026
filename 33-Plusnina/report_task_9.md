# Отчет по задаче 9. Проверка отсортированности

**1. Идея решения и обоснование выбора структуры данных:**
Используется массив. Достаточно пройти по нему и сравнить каждый текущий элемент с предыдущим. Если текущий меньше предыдущего (для неубывания), массив не отсортирован. Это простой и эффективный подход, не требующий копирования данных.

**2. Анализ асимптотики:**
- **Время:** O(n) в худшем случае.
- **Память:** O(1).

**3. Примеры ручных тестов и их важность:**
1. `[1, 2, 2, 3, 4]` → `YES`. Проверяет неубывание (с дубликатами).
2. `[1, 3, 2, 4]` → `NO`. Проверяет наличие нарушения порядка.
