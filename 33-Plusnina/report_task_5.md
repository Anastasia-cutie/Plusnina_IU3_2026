# Отчет по задаче 5. Сумма элементов на чётных позициях

**1. Идея решения и обоснование выбора структуры данных:**
Использование массива и шага цикла. Так как нужно брать каждый второй элемент (индексы 0, 2, 4...), цикл `for` запускается с шагом `i += 2`. Это позволяет избежать лишних проверок условия внутри цикла.

**2. Анализ асимптотики:**
- **Время:** O(n) — проходим половину массива.
- **Память:** O(1).

**3. Примеры ручных тестов и их важность:**
1. `[1, 2, 3, 4, 5, 6, 7]` → `16` (1 + 3 + 5 + 7). Проверяет правильность шага.
2. `[]` → `0`. Граничный случай пустого массива.
