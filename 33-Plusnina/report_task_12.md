# Отчет по задаче 12. Пара с заданной суммой

**1. Идея решения и обоснование выбора структуры данных:**
Используется `HashMap`. Простой перебор пар дал бы O(n^2). Чтобы уложиться в O(n), мы сохраняем уже просмотренные элементы в хеш-таблицу (элемент → его индекс). Для каждого нового элемента `a[i]` мы ищем в таблице его "дополнение" `s - a[i]`. Хеш-таблица обеспечивает быстрый доступ за O(1).

**2. Анализ асимптотики:**
- **Время:** O(n) в среднем (поиск и вставка в HashMap — O(1)).
- **Память:** O(n) для хранения хеш-таблицы.

**3. Примеры ручных тестов и их важность:**
1. `[1, 2, 3, 4, 5], s=5` → `0 3` (1 + 4 = 5). Проверяет, что возвращается пара с минимальными индексами.
2. `[1, 2, 3], s=100` → `-1 -1`. Проверяет отсутствие пары.
