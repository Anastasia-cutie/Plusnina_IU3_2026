# Отчет по задаче 24. Чётно-нечётная сортировка

**1. Идея решения и обоснование выбора структуры данных:**
Используются два списка (`ArrayList`). Мы раскладываем элементы по четности в два списка. Затем сортируем четные по возрастанию (`Collections.sort`), а нечетные — по убыванию (`Collections.reverseOrder`). В конце объединяем списки. Списки выбраны из-за удобства динамического добавления элементов.

**2. Анализ асимптотики:**
- **Время:** O(n log n) — из-за сортировки.
- **Память:** O(n) для хранения двух списков.

**3. Примеры ручных тестов и их важность:**
1. `[1, 2, 3, 4, 5]` → `[2, 4, 5, 3, 1]`. Проверяет, что четные идут первыми по возрастанию, а нечетные — после них по убыванию.
