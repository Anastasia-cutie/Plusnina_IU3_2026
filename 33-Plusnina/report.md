# Отчет по лабораторной работе №1

## Выбранные задачи
Суммарный балл: 15 (порог — 12).
1. Задача 1 (1 балл) — Максимум и минимум
2. Задача 2 (1 балл) — Индекс первого вхождения
3. Задача 5 (1 балл) — Сумма элементов на чётных позициях
4. Задача 9 (1 балл) — Проверка отсортированности
5. Задача 10 (1 балл) — Поиск элемента с условием
6. Задача 12 (1 балл) — Пара с заданной суммой
7. Задача 13 (2 балла) — Сортировка выбором
8. Задача 19 (2 балла) — Объединение двух отсортированных массивов
9. Задача 24 (2 балла) — Чётно-нечётная сортировка

## Расчет асимптотики

| Задача | Время | Память | Обоснование |
|---|---|---|---|
| task_1 | O(n) | O(1) | Один проход по массиву для поиска минимума и максимума. |
| task_2 | O(n) | O(1) | Линейный поиск до первого совпадения. |
| task_5 | O(n) | O(1) | Один проход с шагом 2. |
| task_9 | O(n) | O(1) | Сравнение соседних элементов. |
| task_10 | O(n) | O(1) | Проход с конца для поиска последнего кратного. |
| task_12 | O(n) | O(n) | HashMap хранит пройденные элементы для поиска пары за O(1) в среднем. |
| task_13 | O(n^2) | O(1) | Классическая сортировка выбором (два вложенных цикла). |
| task_19 | O(n + m) | O(n + m) | Слияние двух массивов за один проход с выделением нового. |
| task_24 | O(n log n) | O(n) | Разделение на два списка, сортировка каждого, объединение. |

## Ручные тесты
- **task_1**: проверка граничного случая с одним элементом и выбросом исключения на пустом массиве.
- **task_12**: проверка, что возвращается пара с минимальными индексами.
- **task_19**: проверка слияния массивов с дубликатами и пустыми массивами.
