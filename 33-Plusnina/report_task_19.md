# Отчет по задаче 19. Объединение двух отсортированных массивов

**1. Идея решения и обоснование выбора структуры данных:**
Используется метод двух указателей. Создается новый массив результата. Указатели `i` и `j` идут по первому и второму массивам, сравнивая текущие элементы. Меньший записывается в результат, и его указатель сдвигается. Это позволяет избежать полной пересортировки и работает за линейное время.

**2. Анализ асимптотики:**
- **Время:** O(n + m), где n и m — длины массивов.
- **Память:** O(n + m) для результирующего массива.

**3. Примеры ручных тестов и их важность:**
1. `[1, 3, 5]` и `[2, 4, 6]` → `[1, 2, 3, 4, 5, 6]`. Проверка перемежающихся элементов.
2. `[1, 2, 2]` и `[2, 3]` → `[1, 2, 2, 2, 3]`. Проверка сохранения дубликатов.
