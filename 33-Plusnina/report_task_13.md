# Отчет по задаче 13. Сортировка выбором

**1. Идея решения и обоснование выбора структуры данных:**
Классический алгоритм на массиве. На каждом шаге `i` мы ищем индекс минимального элемента в неотсортированной части (от `i` до конца) и меняем его местами с элементом на позиции `i`. Встроенные функции сортировки не используются согласно заданию. Выбор структуры (массив) обусловлен возможностью доступа по индексу.

**2. Анализ асимптотики:**
- **Время:** O(n^2) — два вложенных цикла.
- **Память:** O(1) — сортировка на месте.

**3. Примеры ручных тестов и их важность:**
1. `[5, 3, 8, 1]` → `[1, 3, 5, 8]`. Базовый случай.
2. `[1, 2, 3, 4]` → `[1, 2, 3, 4]`. Проверка, что уже отсортированный массив не ломается.
